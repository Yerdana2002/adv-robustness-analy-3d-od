# Usage scripts
The scripts in this file can be used to run the experimental pipeline, the evaluation and the visualization. Because we run our code on a server with a slurm structure, most of the scripts are slurm scripts. If your server also uses a slurm structure, you will probably need to change a few things. These scripts are mostly for reference.

## Multi-GPU
For reference on how to use the pipeline with multiple gpus, take a look at "launch_attack.sh"

## Evaluation
For reference on how to use the pipeline with multiple gpus, take a look at "sj_evaluate_results.sh"

## Visualization
For reference on how to use the pipeline with multiple gpus, take a look at "sj_visualize_results.sh"
